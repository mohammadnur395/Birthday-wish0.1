Birthday Wish Version 3

Open index.html in Chrome. This is a front-end prototype with 10 interactive scenes: opening, balloons, envelope, countdown, animated doll-band scene, letter, cake/candle interaction, optional local photos, final letter, and finale.

Personalize using URL query parameters, for example: index.html?from=Nur&to=Ayesha&age=6&message=Happy%20Birthday. For GitHub Pages, upload index.html to the repository root.

Notes: character scenes use animated emoji/CSS rather than custom 3D artwork. The music button plays a simple generated tone, not a copyrighted song. Photos are selected locally in the browser. This version does not include a database or unique per-wish share links; that requires a backend.
