# Birthday Magic — Website V5

A mobile-friendly, single-page birthday surprise website with a 3D-cartoon-inspired + cinematic dark-glow style.

## Included
- Opening screen with sender name, birthday person's name, character style, optional date, and custom wish
- Optional upload of up to two photos (local browser session only)
- Animated balloons with individual wishes
- Double-tap envelope / open-letter button and countdown
- Animated emoji band scene and generated Web Audio melody (not a commercial song)
- Personal letter, cake scene, microphone-based blow detection plus manual candle button
- Uploaded photos displayed beside the cake after candles are blown out
- Memory gallery, finale, confetti, replay
- Responsive mobile layout, star field, aurora glow, reduced-motion support

## Preview locally
Open `index.html` in a modern browser. Some features, especially microphone access, require a secure context (HTTPS or localhost). For best results use Chrome on Android after hosting with GitHub Pages.

## Publish as a NEW GitHub Pages link
1. Create a **new public repository** on GitHub, e.g. `birthday-magic-v5`.
2. Upload `index.html` from this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish. Your new URL will look like `https://YOUR-USERNAME.github.io/birthday-magic-v5/`.

This ZIP cannot create or publish a live URL by itself; GitHub must host it.

## Important notes
- The tune is synthesized with Web Audio and is not “Until I Found You” or another commercial recording.
- Microphone blow detection requires browser permission and HTTPS. If it does not work on a device, use the **Blow out candles** button.
- Photos are previewed locally in the browser and are not uploaded to a server. If you share the website link, other people will not automatically see photos selected on your device.
- This is a static site. Each visitor can personalize the page locally, but it does not save separate birthday wishes in a database.
